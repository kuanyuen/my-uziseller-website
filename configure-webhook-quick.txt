📋 第一步：复制 Webhook URL
─────────────────────────────────────────────────────────────
https://uziseller-uzi-seller.vercel.app/api/billplz-webhook
─────────────────────────────────────────────────────────────

🌐 第二步：打开配置页面
─────────────────────────────────────────────────────────────
https://www.billplz.com/enterprise/settings/webhooks
─────────────────────────────────────────────────────────────

✏️ 第三步：填写表单

在 Billplz 页面中：

1. 点击 [Add Webhook] 或 [Create New Webhook]

2. 粘贴 Webhook URL（上面第一步复制的）

3. Signature Method: 
   ○ None
   ● X Signature  ← 选这个！

4. Events（事件）:
   ☑ bill.paid       ← 勾选
   ☑ bill.failed     ← 勾选
   ☐ bill.deleted

5. Collection（可选）:
   0uklil7m

6. 点击 [Test Webhook]
   ✅ 返回 200 OK 或 401 = 正常

7. 点击 [Save] 保存

╔════════════════════════════════════════════════════════════════╗
║  🎉 配置完成！                                                ║
╚════════════════════════════════════════════════════════════════╝

🧪 验证配置

1. 访问: https://uziseller.com
2. 选择任意产品并下单
3. 完成 Billplz 支付
4. 检查订单状态: https://uziseller.com/order-status.html

如果订单状态自动从 "pending_payment" 变为 "paid"，
说明 Webhook 配置成功！✅
